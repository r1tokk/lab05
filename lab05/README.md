## Опис проєкту
Цей проєкт демонструє використання генераторів у Python для роботи з нескінченними послідовностями без надмірного споживання оперативної пам'яті. Використано функцію `yield` та бібліотеку `itertools` (`islice`, `accumulate`) для створення ефективного пайплайну обробки даних.

## Лінивість обчислень (Laziness)
У цьому проєкті потік чисел Фібоначчі є нескінченним (`while True: yield a`). Якби ми спробували матеріалізувати його у список (через `list()` або зрізи `[:]`), програма б зависла через нестачу пам'яті (OOM). 
Ліниві обчислення вирішують цю проблему: значення обчислюються (ітератор просувається вперед) лише тоді, коли споживач (наприклад, `islice` всередині `take`) запитує наступне значення через `next()`. Таким чином ми можемо брати вікна (`sliding_window`) або пропускати елементи (`drop`) з нескінченного джерела, утримуючи в пам'яті лише поточний мінімально необхідний стан.
